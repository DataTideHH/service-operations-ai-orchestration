# ADR 0005: Consume a versioned analytics handoff without a runtime dependency

## Status

Accepted for V4.

## Decision

V4 replaces the standalone properties snapshot with the exact JSON handoff generated by `fabric-service-operations-analytics`. The consumer commits both the producer artifact and its Draft 2020-12 JSON Schema. Startup validates the JSON against that schema and then independently reconciles overall and assigned-team counts, derived rates, unique groups and breach-rate ordering.

The handoff records its producer, source repository and revision, deterministic scenario, ingestion batch and SHA-256 fingerprints of the upstream evidence inputs. Tool responses expose this provenance. The comparison dimension is explicitly `assigned_team`, and the external tool contract advances to version `2.0.0` while retaining exactly two read-only tools.

## Consequences

- The AI evidence is traceable to a reviewed analytics baseline rather than a separate hand-written scenario.
- Both repositories remain independently buildable without network access at runtime.
- V3 and V4 evaluation artifacts are intentionally incompatible because the snapshot, schema and case catalog changed.
- V4 keeps database access, RAG, vector stores, additional tools, a frontend and causal claims out of scope.
